Кратко о проекте:

Сканирование QR кодов для вывода дополнительной информации в дополненной реальности (AR). На учебных стендах размещается QR код, сканируешь его в приложении и выводятся кнопки в AR пространстве вокруг, при нажатии открывается панель с доп.информацией
